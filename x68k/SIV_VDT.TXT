	内容はわかりづらいですが、興味がある人は、がまんして見て下さい(^^;

お約束事：

	取敢えず、データの単位は以下のように解釈して読んで下さい。

	B = Byte --------> 8 Bit
	W = Word --------> 16 Bit
	L = Long Word ---> 32 Bit

	数値データは全て符号付きです。
-----------------------------------------------------------------------------------------------
サイズ          : 名称                  : 意味

3 Byte          : Data ID               : プログラム識別データ。'SiV'。
? Byte          : Data ID               : $0aで終わるデータ。コメント用。
Long Word       : Poster Len            : ポスター用の画像データのサイズ
Poster Len      : Poster Data           : ポスター用の画像データ。Poster Lenバイト。
Long Word       : Quality               : 画質。１から１００まで。
Long Word       : Type                  : 色質。０から３まで。
Long Word       : Poster Voice Size     : ポスター用の音声データのサイズ。ただしADPCMレートによ
					  り固定。
Poster Voice Len: Poster Voice Data     : ポスター用の音声データ。Poster Voice Sizeバイト。
Long Word       : Time Scale            : Time Scale/60秒に１フレーム再生する。60/30/20/15/12
					  /10/6/5/4/3/2を指定する。
Long Word       : ADPCM Rate            : ADPCMレート。０と３と４。それぞれ、無音、7.8KHz、15.6
					  KHZとなる。
Long Word       : Flame Number          : フレーム数。ただし、ポスターは除く。
Long Word       : Flame Len       ┐    : 画像データのサイズ。ただし無圧縮時は30720バイト固定。
				  │      圧縮時は最大30720バイト。
Flame Len       : Flame Data      ├┐  : 画像データ。
Flame Voice Len : Flame Voice Data┘│  : 音声データ。Flame Voice Sizeバイト。
				　　↓
┌─────────────────┴──┐
｢Flame Len｣､｢Flame Data｣､｢Flame Voice Size｣の３つを ｢Flame Number｣だけ、繰り返す。

では、秒間１２フレーム、サンプリング周波数１５.６ＫＨｚ、無圧縮データの例を以下に示します。

	┌─────┐
	│B   'S'   │
	└──┬──┘
	┌──┴──┐
	│B   'i'   │
	└──┬──┘
	┌──┴──┐
	│B   'V'   │
	└──┬──┘
      ┌──→┤
      │┌──┴──┐
      ││B   ??    │
      │└──┬──┘
      └───┤$0aが現れるまで続ける。
	┌──┴──┐
	│L  30720  │ポスター画像データのサイズ。ロングワードで30720固定。
	└──┬──┘
	┌──┴──┐
	│30720 Byte│ポスターの画像データが、30720バイト続く。
	└──┬──┘
	┌──┴──┐
	│L   ?     │下の色質から、無圧縮とみなして画質は無視する。
	└──┬──┘
	┌──┴──┐
	│L   0     │色質０は無圧縮データ。
	└──┬──┘
	┌──┴──┐
	│L   650   │ポスター音声データのサイズ。ロングワードで650。
	└──┬──┘15.6KHz､1秒7800ﾊﾞｲﾄ/12 = 650ﾊﾞｲﾄ
	┌──┴──┐
	│  650 Byte│実際の音声データが、650バイト続く。
	└──┬──┘
	┌──┴──┐
	│L    5    │タイムスケール。60/5=12｡IOCSのVDISPSTにそのまま使える値。
	└──┬──┘
	┌──┴──┐
	│L    4    │サンプリングレート。これもADPCMのIOCSでそのまま使える値。
	└──┬──┘
	┌──┴──┐
	│L   ??    │画像の枚数。
	└──┬──┘
      ┌──→┤
      │┌──┴──┐
      ││30720 Byte│画像データが、30720バイト続く。
      │└──┬──┘
      │┌──┴──┐
      ││  650 Byte│実際の音声データが、650バイト続く。
      │└──┬──┘
      └───┤画像の枚数だけ続ける。
	┌──┴──┐
	│　終わり  │
	└─────┘

データファイルには解像度データが含まれていませんので、解像度は128x120固定となります。
無圧縮の画像データは、１ライン256バイトで、１２０ラインの矩形データです。

	1ﾄﾞｯﾄ = GGGGGRRRRRBBBBBI = 1ワード
	       MSB            LSB

	これは、Ｘ６８０００の６５５３６色モードのピクセルデータそのものです。

	┌──128ﾄﾞｯﾄ ──┐
	┌──256ﾊﾞｲﾄ ──┐
	┌────────┐┐
	│              　││
	│              　││120ﾗｲﾝ
	│              　││
	│              　││
	└────────┘┘

従って、
	256x120 = 30720ﾊﾞｲﾄ

というわけです。
